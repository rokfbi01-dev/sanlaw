상속·유류분 계산기

법정상속분(민법 §1009)과 유류분(민법 §1112·§1113)을 자동 계산합니다 · 산 법무사 김재섭 행정사 사무소

1. 재산 입력

2. 배우자 유무

3. 상속인 입력 배우자 제외

유형: 자녀(직계비속) → 1순위 / 부모(직계존속) → 자녀 없을 때 / 형제자매 → 자녀·부모·배우자 모두 없을 때.

계산 결과

⚖ 본 계산기는 일반적인 개산(槪算) 보조용입니다. 실제 사건은 특별수익·기여분·증여 시기·평가액 등에 따라 결과가 달라질 수 있으므로 개별 검토가 필요합니다.
※ 형제자매의 유류분은 2024. 4. 25. 헌법재판소 위헌결정(2020헌가4 등)으로 폐지되어, 형제자매는 상속분은 인정되나 유류분은 0으로 계산됩니다.
