# 세션 교훈 노트 (내부용 — 사이트 비공개)

> 이 파일은 Claude Code 세션 간 교훈을 축적하는 **유일한 공식 저장소**입니다.
> `.claude/` 폴더는 Cloudflare Pages 배포에서 제외되므로 sanlaw.co.kr에 노출되지 않습니다.

## 기록 규칙 (클로이 준수사항)

1. **현재 세션에서 실제 일어난 일만 기록** — 지난 세션을 "기억나는 척" 재구성 금지(환각 방지, CLAUDE.md §3-1).
2. **추가 전용(append-only)** — 기존 항목은 수정·삭제하지 않고 맨 아래에 새 항목을 덧붙인다. (잘못된 항목은 삭제 대신 `~~취소선~~ + 정정 항목 추가`)
3. 항목당 **5줄 이내**, 다음 형식을 따른다.
4. 기록 후 반드시 커밋·푸시해야 다음 세션에 전달된다.

## 항목 형식

```
### YYYY-MM-DD — 작업 요지 한 줄
- 분류: [법률정확성 | 사이트작업 | 워크플로 | 도구환경]
- 교훈: (다음 세션이 똑같은 실수를 안 하려면 알아야 할 것)
- 근거: (이번 세션에서 실제 있었던 일)
```
